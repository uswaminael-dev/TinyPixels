# 🎨 Pixel Art Pro

An interactive pixel art generator built with **HTML, CSS, and Vanilla JavaScript**.  
Create pixel art, use drawing tools, save your work, and share it — all in the browser.

## ✨ Features
- Pen, Erase, Fill, Line, and Mirror tools
- Undo/Redo history
- Custom color picker
- Resizable grid (16×16, 32×32, 64×64)
- Export as PNG
- Save/Load JSON files
- Preset gallery with sample designs
- Light/Dark mode toggle

## 🚀 Deployment
This project is **ready for Vercel**:
1. Push to GitHub.
2. Connect your repo to Vercel.
3. Deploy — no backend required.
